# EduShield Phase 7 — Lightweight Background Images & Animations

This phase adds a lightweight visual background system without background videos.

## What changed
- Added animated particles, glowing orbs, subtle wave motion and rotating rings.
- Reused the existing building, tree and car PNG assets at very low opacity.
- Added disaster-specific background atmospheres for Earthquake, Fire, Flood, Cyclone, Landslide, Biological, Radiological and Chemical hazards.
- Added `prefers-reduced-motion` support.
- Background visuals are behind the existing UI and do not capture clicks.
- Backend, authentication, MongoDB, quizzes, rankings, staff dashboard and emergency-kit features were not changed.

## Run
Use the same Phase 6 backend setup and `.env` file. No database reseeding is required.
